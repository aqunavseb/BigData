# BigData

Proyectos, pipelines de datos y análisis exploratorio (EDA) en **Big Data & Data Analytics**.

## Estructura del repositorio

### 1. `big_data/` (Procesamiento ETL & Datos Relacionales)
* **`python_big_data/`**: Scripts de conexión y procesamiento de datos en Python (`conexion.py`, `main.py`).
* **Datasets relacionales (CSV)**: Tablas de hechos y dimensiones para modelado de ventas:
  * `ventas.csv` y `detalle_venta.csv`
  * `clientes.csv`, `vendedores.csv`, `articulos.csv`, `canal.csv`, `ubicaciones.csv`

### 2. `notebooks/` (Análisis, Notebooks y Base de Datos)
* **`BIG_DATA_AMERICANS.ipynb`**: Notebook Jupyter con análisis exploratorio de datos, limpieza, transformaciones y visualizaciones.
* **`2.1.4_BD Americans.sql`**: Script DDL/DML con la estructura y carga de datos de la base de datos Americans.
* **Datasets**: Hojas de cálculo procesadas (`Americans_limpio.xlsx` y `Americans.xlsx`).
